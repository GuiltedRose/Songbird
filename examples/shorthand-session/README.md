# Mixed native and Mini shorthand

Open with `songbird examples/shorthand-session`. The two percussion tracks use
sound constructors, alternating sample-end fractions, fast and decay. The melody
uses the original Mini spelling; bass uses native note sequencing. All instruments
are generated locally by Songbird. No sound download or additional runtime is needed.

Read [Mini syntax](../../docs/MINI_NOTATION.md#familiar-sound-constructors) and the
[offline sound catalogue](../../docs/SOUNDS.md). This example has not been rendered
or played by the implementer; use the normal operator checks before acceptance.
