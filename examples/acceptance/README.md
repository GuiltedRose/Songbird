# Integrated analytic example

Open this directory with Songbird. `composition.sb` combines a drum pattern,
oscillator bass, polyphonic melody, imported FLAC and WAV, clip edits, effects,
and a custom analytic vowel voicebank. The selected generation is named in
`project.toml`. `exports/master.flac` and `exports/master.wav` are actual renders.

Every bundled audio sample was generated by `examples/make_project.rs`. No human
recording is included and no microphone recording is simulated. The analytic
vowel is an engine fixture, not an intelligible English singer. Generated audio
in this directory is dedicated to the public domain under CC0-1.0. The generator
and application source remain under the repository's BSD-3-Clause license.

Use `record opening flac` to capture a real voiceover, then add the saved take's
relative path in an `import` statement at the desired timestamp. For full English
singing, use your own authorized phoneme bank following docs/VOICEBANKS.md.

Regenerate this example in a new directory with:

    cargo run --locked --offline --example make_project -- /absolute/new/path

An optional second argument imports a real, existing voiceover file.
