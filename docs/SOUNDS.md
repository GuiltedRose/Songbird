# Songbird sound library

This is the offline catalogue for Songbird's own sound collections. Entries here
identify resources actually shipped with the project. Recorded collections can
be added as the sound repository grows; unavailable collections are not listed
as installed.

## Available collections

| Collection | Type | Available contents |
|---|---|---|
| Native percussion | Procedural audio generated by Songbird | 14 distinct percussion voices listed below |
| Native instruments (0.9.0) | Note-aged additive synthesis | 20 pitched voices listed below |

## Native instrument bank

Use `instrument NAME` or `synth NAME` in an ordinary note track. These are
distinct procedural timbres, not recordings or realistic acoustic sample banks.
No downloads, plugins, or external services are required.

Every pitched voice also accepts [Mini notation](MINI_NOTATION.md), including
`note("c4 <e4 g4>").s("piano")`. See `examples/mini-instruments` for a mixed
ensemble using pitched and percussion constructors together.

Use the shorthand or full ID in `.s("ag")`, `instrument ag`, or `synth ag`.
A dash means to use the full ID.

| Shorthand | Songbird sound ID | Sound |
|---|---|---|
| — | `piano` | Struck keys with a bright attack and fading overtones |
| `ep` | `electric-piano` | Electric keys with a bell-like attack |
| — | `organ` | Sustained drawbar-style keys |
| — | `accordion` | Sustained reed keys |
| `ag` | `acoustic-guitar` | Bright plucked guitar |
| `ng` | `nylon-guitar` | Softer, darker plucked guitar |
| `eg` | `electric-guitar` | Clean electric guitar with a longer decay |
| — | `banjo` | Bright, short plucked strings |
| — | `mandolin` | Crisp plucked strings |
| `ub` | `upright-bass` | Dark plucked acoustic-style bass |
| `eb` | `electric-bass` | Sustained plucked electric-style bass |
| — | `violin` | Bright bowed string voice |
| — | `cello` | Darker bowed string voice |
| — | `strings` | Bowed strings with a slower onset |
| — | `flute` | Soft wind voice with few overtones |
| — | `clarinet` | Dark sustained reed voice |
| — | `saxophone` | Brighter sustained reed voice |
| — | `trumpet` | Bright brass voice |
| — | `marimba` | Short wooden mallet tone |
| — | `vibraphone` | Ringing mallet tone with gentle tremolo |

For folk and country, try guitars, banjo, mandolin, fiddle (`violin`), and upright
bass. For jazz and soul, try electric piano, organ, saxophone, trumpet, and
vibraphone. Piano, bowed strings, flute, and clarinet suit chamber arrangements.

Each voice has its own partial balance, onset, and decay or sustain profile.
Plucked and struck voices darken as they decay. Bowed, wind, reed, and organ
voices sustain for the note's duration. Vibraphone includes gentle amplitude
modulation. Partials fade before Nyquist, including inharmonic struck modes.
The same renderer supplies live playback and exports. Existing waveform sounds
and percussion retain their behavior.

```text
track guitar {
    instrument ng
    notes "[C3,E3,G3]:2 [F3,A3,C4]:2"
    adsr 0.002 0.08 0.9 0.08
    gain -12db
    reverb 0.12
    loop
}
```

Track ADSR, pitch bends, transpose, gain, pan, and effects remain available.
Leave enough note duration for a struck voice's decay: notes are still gated
by the existing track ADSR and do not add an automatic release beyond the gate.
The electric-guitar voice is clean. Bowed and wind voices do not simulate player
articulation; these timbres are starting points for arrangement and sound design.

Audition every voice in `examples/instrument-bank` (one voice per bar), or open
`examples/folk-band`, `examples/jazz-combo`, and `examples/chamber` for ensemble
starting points. These are synthesized arrangements; listening and hardware
performance acceptance remain operator checks.

## Native percussion and shorthand

These are synthesized sounds, not recordings of a particular drum machine.
There is no download or external sound service involved.

Both native `pattern` and Mini percussion accept these identifiers:

| Shorthand | Songbird sound ID | Sound |
|---|---|---|
| `bd` | `kick` | Bass drum |
| `sd` | `snare` | Snare drum |
| `hh` | `hat` | Closed hi-hat |
| `oh` | `open-hat` | Open hi-hat with a longer decay |
| `cp` | `clap` | Handclap |
| `rim` | `rimshot` | Short rim click |
| `cr` | `crash` | Noisy metallic crash |
| `rd` | `ride` | More tonal metallic ride |
| `ht` | `high-tom` | Higher-pitched tom |
| `mt` | `mid-tom` | Middle-pitched tom |
| `lt` | `low-tom` | Lower-pitched tom |
| `sh` | `shaker` | Short noisy shake |
| `cb` | `cowbell` | Paired metallic tones with upper partials |
| `tb` | `tambourine` | Short metallic jingle |

The full Songbird IDs continue to work. Sounds have distinct native synthesis;
shorthand is not a promise to reproduce another application's recordings.

```text
track drums {
    s("bd sd [hh hh] oh").dec(.4)
    gain -12db
}
```

See [Mini syntax](MINI_NOTATION.md#familiar-sound-constructors) for constructors,
chaining and mixed native/Mini compositions.

## Your project's local sounds

Use `drum NAME "samples/FILE.wav"` to map an identifier to a local WAV/FLAC file
inside the current project. In either percussion frontend, an explicitly declared
local identifier takes priority over the built-in shorthand:

```text
track custom {
    drum bd "samples/my-kick.wav"
    s("bd*2 hh*4").end("<.5 1>")
    gain -12db
}
```

Here `bd` uses your file and `hh` uses the native closed hat. Songbird reads the
actual local source; it does not fetch a similarly named sound. Other declared local percussion identifiers remain available through Mini and
sound constructors. Native `pattern` accepts the listed shorthand/full names. Project mappings are local declarations, not globally
installed collections. Add named recorded collections to this catalogue only
when their actual files/index are available and verified for inclusion.
