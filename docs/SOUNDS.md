# Songbird sound library

This is the offline catalogue for Songbird's own sound collections. Entries here
identify resources actually shipped with the project. Recorded collections can
be added as the sound repository grows; unavailable collections are not listed
as installed.

## Available collections

| Collection | Type | Available contents |
|---|---|---|
| Native percussion | Procedural audio generated by Songbird | 14 distinct percussion voices listed below |

These are native synthesized sounds, not recordings of a particular drum machine.
There is no download or external sound service involved. A shorthand identifies a
sound; it does not select an external collection.

## Native percussion and shorthand

Both native `pattern` and Mini percussion accept these identifiers:

| Shorthand | Songbird sound ID | Sound |
|---|---|---|
| `bd` | `kick` | Bass drum |
| `sd` | `snare` | Snare drum |
| `hh` | `hat` | Closed hi-hat |
| `oh` | `open-hat` | Open hi-hat with a longer decay |
| `cp` | `clap` | Handclap |
| `rim` | `rimshot` | Short rim click |
| `cr` | `crash` | Noisy metallic crash |
| `rd` | `ride` | More tonal metallic ride |
| `ht` | `high-tom` | Higher-pitched tom |
| `mt` | `mid-tom` | Middle-pitched tom |
| `lt` | `low-tom` | Lower-pitched tom |
| `sh` | `shaker` | Short noisy shake |
| `cb` | `cowbell` | Paired metallic tones with upper partials |
| `tb` | `tambourine` | Short metallic jingle |

The full Songbird IDs continue to work. Sounds have distinct native synthesis;
shorthand is not a promise to reproduce another application's recordings.

```text
track drums {
    s("bd sd [hh hh] oh").dec(.4)
    gain -12db
}
```

See [Mini syntax](MINI_NOTATION.md#familiar-sound-constructors) for constructors,
chaining and mixed native/Mini compositions.

## Your project's local sounds

Use `drum NAME "samples/FILE.wav"` to map an identifier to a local WAV/FLAC file
inside the current project. In either percussion frontend, an explicitly declared
local identifier takes priority over the built-in shorthand:

```text
track custom {
    drum bd "samples/my-kick.wav"
    s("bd*2 hh*4").end("<.5 1>")
    gain -12db
}
```

Here `bd` uses your file and `hh` uses the native closed hat. Songbird reads the
actual local source; it does not fetch a similarly named sound. Other declared local percussion identifiers remain available through Mini and
sound constructors. Native `pattern` accepts the listed shorthand/full names. Project mappings are local declarations, not globally
installed collections. Add named recorded collections to this catalogue only
when their actual files/index are available and verified for inclusion.
